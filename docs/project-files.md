# 工程文件与磁盘布局

## 一个工程在磁盘上长什么样

```
song.glz              # 工程文件（RON 文本，可直接读）
song.glz.bak          # 上一次保存的版本
song.glz.autosave     # 崩溃快照，只在异常退出后残留
song.media/           # 收集进来的采样、录音 take
    rec-1699...-a1.wav
    kick.wav
```

`.glz` 是 RON 格式的纯文本：`version` + 整个工程文档。字段缺失自动取默认值，未知字段忽略，
所以旧版本文件能被新版本读。文件的 `version` 比当前程序还新时会**直接拒绝打开**——
强行读会丢掉新版写进去的数据，再保存就永久丢了。

当前格式版本 10。更早的文件在加载时按版本跑迁移链：v4 及更早的 `ChannelStrip` → mixer、
v6 之前的 tick ×10、v7 之前的音频裁剪窗口、v8 之前的效果参数、v9 之前的曲线归一化。

## 保存

`Save` 的写入顺序是：

1. 写入 `<name>.glz.tmp`，`sync_all` 刷到磁盘；
2. 已存在旧文件时，把它复制成 `<name>.glz.bak`（尽力而为，失败不影响本次保存）；
3. 把 `.tmp` 原子重命名成 `<name>.glz`。

进程在保存中途被杀，旧工程仍然完整。`.tmp` 只在那种情况下会残留，可以删。

`.bak` 是"上一次保存"。想回退一版，把 `.bak` 复制成 `.glz` 再打开即可。

## 自动保存与崩溃恢复

未保存的改动会在后台写成快照：

| 情况 | 位置 |
| :--- | :--- |
| 工程已存过盘 | 工程同目录的 `<name>.glz.autosave` |
| 从未存过盘 | `%APPDATA%\GlitcherZ\data\autosave\Untitled.glz`（macOS / Linux 对应各自的 app data） |

节奏：停止编辑 30 秒后写一次；一直在编辑时，最多每 60 秒写一次。写盘发生在 UI 帧尾，
不碰音频线程。

**快照文件存在 = 上次没有正常退出。** 手存成功、明确丢弃、以及关闭窗口时文档是干净的，
这三条路径都会删掉快照，所以启动时看到文件就说明有活没保住。启动会弹 `Recover unsaved work`：

| 按钮 | 行为 |
| :--- | :--- |
| `Recover` | 载入该快照并设为未保存状态（标题带 `*`），其它快照不动 |
| `Discard all` | 删掉列出的所有快照 |
| `Later` | 只关掉提示，文件留着，下次启动还会问 |

启动只会检查**最近工程列表里那些工程**旁边的快照，加上未命名槽位。如果工程不在最近列表里
（例如从别的机器拷来），快照不会被自动发现，手动把 `.autosave` 改名成 `.glz` 打开即可。

## 媒体文件

采样、SoundFont、鼓机槽位、音频片段都存**路径字符串**：

- 文件在工程目录下 → 存相对路径（`song.media/kick.wav`）；
- 在工程目录外 → 存绝对路径；
- 分隔符一律写 `/`；读的时候也接受老 Windows 工程留下的 `\`。

相对路径按"工程文件所在目录"解析，所以整个工程文件夹可以整体搬走或分享。

### 收集（Collect Media Files…）

把每个被引用的外部文件复制进 `<name>.media/`，并把文档里的路径改写成相对路径。
一步 undo 可以整体撤回。

- 目标目录里有同名同大小的文件 → 视为已收集，跳过（所以重复执行不会复制第二份，也不会把
  几百 MB 的 SoundFont 拷两遍）；
- 同名但大小不同 → 落成 `名字 (2).wav`。

### 重定位（Relocate Missing Media…）

打开工程时若有文件找不到，会弹缺失列表。选一个目录后按**文件名**在该目录下搜（最多 4 层、
最多 20000 个条目、大小写不敏感）：

- 找到 → 改写路径并重建引擎；
- 没找到 → 留在列表里，提示框不关，可以再选一个目录。

提示框底部 `Continue without them` 先继续编辑；缺失项可以之后用
`File ▸ Relocate Missing Media…` 再处理（有缺失时该菜单项才可点）。

## 录音 take

音频 take 写在 `<name>.media/rec-<毫秒时间戳>-a<轨号>.wav`。因为要落盘，未保存的工程不能
录音频——会提示先存盘。

## 应用数据

| 内容 | 位置 |
| :--- | :--- |
| 最近工程、输出设备、采样率、缓冲、窗口状态 | `%APPDATA%\GlitcherZ\data\app.ron` |
| 未命名工程的崩溃快照 | `%APPDATA%\GlitcherZ\data\autosave\Untitled.glz` |

删掉 `app.ron` 等于恢复出厂设置（最近列表、音频设备偏好都会重置），工程文件不受影响。
