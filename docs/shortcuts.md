# 快捷键与鼠标手势

快捷键里的 `Ctrl` 是**物理 Control 键**，macOS 上也是（不是 `Cmd`）；`Shift` / `Alt` 同理。

## 全局

| 键 | 作用 |
| :--- | :--- |
| `Space` | 播放 / 暂停；录音中是 punch out（收尾并继续播放） |
| `Home` | 回到开头 |
| `End` | 跳到编曲末尾 |
| `,` / `.` | 上一个 / 下一个标记 |
| `Ctrl` + `←` / `→` | 按小节前后跳 |
| `Ctrl+N` / `Ctrl+O` | 新建 / 打开 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+Z` / `Ctrl+Y` | undo / redo |
| `Ctrl+L` | 把选中乐器接到 / 摘下电脑键盘 |
| `R` | 开始录音（卷帘持有焦点时除外） |
| `Z` / `X` | 降 / 升八度（24–84 之间） |

走带键在任何焦点下都有效；正在编辑文本框时除外（那时 `Space` 就是空格）。

## 弹奏（电脑键盘）

`A W S E D F T G Y H U J K O L P ;` 是半音阶，从当前八度基准起。

卷帘持有焦点时这些字母全是编辑命令，不发声；时间轴持有焦点时 `G` / `T` / `K` / `S`
被命令占用（其余字母照常发声）。想纯粹试音就切到 `Patch` 或 `Inspector` 视图。

## 时间轴（需要焦点）

| 键 | 作用 |
| :--- | :--- |
| `G` | 抓取移动选区；混合类型选区（MIDI / Curve / Audio）一起移动，各组沿自己的行滑动 |
| `Shift+D` | 复制选区；同样支持混合类型选区 |
| `T` | 扩展/缩短片段尾边；模态中 `S` 切到首边 |
| `Shift+T`（`Alt+T` 备用） | 平铺：向右拖动增加整段重复、往左减少；已平铺片段再按一次 = 调整重复份数 |
| `X` / `Y` | 模态中锁时间轴 / 锁轨道行 |
| `K` | 刀片，一次点击切一刀 |
| `Delete` | 删除选中片段 |
| `Ctrl+G` / `Ctrl+Shift+G` | 编组 / 解组 |
| `F2` | 重命名选中片段 |
| `Esc` | 取消模态 / 取消刀片 |

## 钢琴卷帘（需要焦点）

| 键 | 作用 |
| :--- | :--- |
| `D` | 切换 `Select` / `Draw` 模式（`Esc` 也能退出 `Draw`） |
| `G` | 抓取移动 |
| `S` | 缩放 |
| `T` | 拉伸；模态中 `S` 切到首边 |
| `Shift+D` | 复制并抓取 |
| `K` | 刀片 |
| `X` / `Y` | 模态中锁时间轴 / 锁音高 |
| `Delete` | 删除选中音符 |
| `↑` / `↓` | 上下一律 |
| `Shift` + `↑` / `↓` | 上下八度 |
| `←` / `→` | 左右一格（跟随当前网格） |
| `Esc` | 退出模态 / 退出 `Draw` |

## 鼠标

### 时间轴

| 操作 | 结果 |
| :--- | :--- |
| 拖片段主体 | 移动（小节吸附） |
| 拖右边缘 | 扩展/缩短片段长度；平铺片段的周期随之缩放 |
| 双击空轨道 | 插入片段并自动选中（音频轨弹音频文件选择） |
| 双击片段 | 进 `Edit` |
| `Alt` + 双击 / `F2` | 重命名片段 |
| 右键片段 | 删除 |
| 标尺点击 / 拖 | 定位 |
| 标尺 `Ctrl` + 拖 | 画 song loop |
| 标尺右键 | 加 / 删标记 |
| 右键行首轨道名 | 重命名轨道 |
| 拖行首圆点 | 调整轨道顺序 |
| `Ctrl` + 滚轮 / `Ctrl` + `Alt` + 滚轮 | 水平缩放 / 行高 |
| 中键拖 | 平移 |

### 钢琴卷帘

| 操作 | 结果 |
| :--- | :--- |
| 拖音符 | 移动 |
| 拖音符边缘 | 裁剪 |
| `Ctrl` + 拖 | 复制 |
| 双击空白 | 插入音符 |
| `Shift` / `Ctrl` + 点击 | 加选 / 切换选择 |
| 右键 | 删除 |
| 滚轮 / `Shift` + 滚轮 | 滚动音高 / 沿时间轴滚动 |
| `Ctrl` + 滚轮 / `Ctrl` + `Alt` + 滚轮 | 时间缩放 / 音高缩放 |
| 中键拖 | 平移 |

### 曲线编辑器

| 操作 | 结果 |
| :--- | :--- |
| 点击空白 | 加锚点 |
| 拖锚点 | 移动 |
| 右键 | 删除该处锚点 |

### Patch

| 操作 | 结果 |
| :--- | :--- |
| 中键拖 | 平移 |
| 滚轮 | 缩放 |
| 空白右键 / `Shift+A` | 添加节点菜单 |
| 拖端口 | 连线 |
| `Ctrl` + 右键拖 | 划断连线 |
| 点连线中点 | 插入效果 / 删除连线 |
| 框选 | 多选 |
| `Delete` | 删除选中节点或连线 |
| 双击节点 | 进 `Inspector` |

画布上还有一层焦点逻辑：`G` / `T` / `K` 等命令只在时间轴或卷帘拿到焦点时生效，
工具栏左侧的 `no keyboard focus` 提示消失即表示已就绪。点一下那片区域即可。
