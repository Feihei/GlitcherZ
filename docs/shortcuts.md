# 快捷键与鼠标手势

下文快捷键里的 `Ctrl` 指**命令修饰键**：Windows / Linux 上是 `Ctrl`，macOS 上是 `⌘`（物理 `Control` 也照样可用）。唯一的例外是 `Ctrl+Tab` / `Ctrl+Shift+Tab`——它固定用物理 `Control`（macOS 的 `⌘+Tab` 是系统应用切换器）。`Shift` / `Alt` 照字面。

按住 `Ctrl` 拖动片段 / 音符 / 曲线锚点会**临时关闭吸附**，落点按最近的 tick 计算；松开即恢复，状态栏会显示 `Snap off`。

时间轴的吸附粒度由工具栏下拉框选择（`Bar` / `Beat` / `Step`，默认 `Beat`），
影响拖拽、裁剪、刀片与 `G` / `T` / `Shift+T` 的步进；`Ctrl` 不改变这三个模态的步进。

## 全局

| 键 | 作用 |
| :--- | :--- |
| `Space` | 播放 / 暂停；录音中是 punch out（收尾并继续播放）；在 `Editor` 标签下是试听当前片段 |
| `Home` | 回到开头 |
| `End` | 跳到编曲末尾 |
| `,` / `.` | 上一个 / 下一个标记 |
| `Ctrl` + `←` / `→` | 按小节前后跳 |
| `Ctrl+N` / `Ctrl+O` | 新建 / 打开 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+Z` / `Ctrl+Y` | undo / redo |
| `Ctrl+L` | 把选中乐器接到 / 摘下电脑键盘 |
| `Tab` / `Shift+Tab` | 按 `Timeline → Edit → Patch → Inspector` 循环切换视图 |
| `Alt+1` .. `Alt+4` | 直接跳到第 N 个视图（顺序同上） |
| `R` | 开始录音（卷帘持有焦点时除外） |
| `Z` / `X` | 降 / 升八度（音区 0–8） |

走带键在任何焦点下都有效；正在编辑文本框时除外（那时 `Space` 就是空格）。

`Tab` 被视图切换独占：egui 默认的**控件焦点遍历**因此在全局范围内关闭——`File` / `Edit`
菜单和一般按钮只能用鼠标点。这是有意的取舍（`Tab` 换视图比 Tab 走一遍控件更常用）。
文本框里 `Tab` 不切视图，输入不受影响。

## 弹奏（电脑键盘）

`A W S E D F T G Y H U J K O L P ;` 是半音阶，从当前音区起。

音区由 `Keyboard In` 节点决定：节点上的音条括住 `G(octave)..G(octave+2)`，
电脑键盘从这条窗口的 **C** 开始（默认八度 4 → `C4`，音条 `G3..G5`）。所以
`Z` / `X` 与节点上的 `Oct -` / `Oct +` 是同一个值——改一处，音条和手指下的
键一起动；这个值存盘，重新打开工程还在。没有 `Keyboard In` 节点时，`Z` /
`X` 才退回到全局基准（`C1`–`C6`）。

卷帘持有焦点时这些字母全是编辑命令，不发声；时间轴持有焦点时 `G` / `T` / `K` / `S`
被命令占用（其余字母照常发声）。想纯粹试音就切到 `Patch` 或 `Inspector` 视图。

## 时间轴（需要焦点）

| 键 | 作用 |
| :--- | :--- |
| `G` | 抓取移动选区；混合类型选区（MIDI / Curve / Audio）一起移动，各组沿自己的行滑动 |
| `Shift+D` | 复制选区，副本拥有独立数据（之后编辑互不影响）；同样支持混合类型选区 |
| `Alt+D` | 复制选区并共享原片段的数据（关联复制，改一处所有引用者同步） |
| `Ctrl+C` / `Ctrl+V` | 复制选中片段 / 粘贴到播放头（保持选区的相对位置） |
| `T` | 扩展/缩短片段窗口；向右扩展会同步延长可编辑内容（卷帘新区域可直接写），`T+S` 向左扩展在前方补空白、音符保持原位；不产生平铺 |
| `Shift+T`（`Alt+T` 备用） | 平铺：向右拖动增加整段重复、往左减少；已平铺片段再按一次 = 调整重复份数 |
| `X` / `Y` | 模态中锁时间轴 / 锁轨道行 |
| `K` | 刀片，一次点击切一刀 |
| `Delete` / `Backspace` | 删除选中片段 |
| `Ctrl+G` / `Ctrl+Shift+G` | 编组 / 解组 |
| `H` / `Alt+H` | 静音选中片段 / 恢复整个编曲的静音（Blender 的 hide / reveal-all） |
| `Ctrl+A` / `Ctrl+Shift+A` | 全选所有轨道的片段 / 取消选择 |
| `-` / `=` | 水平缩放，一档 1.3×，锚在视图中心（`Ctrl` + 滚轮是连续缩放） |
| `F2` | 重命名选中片段 |
| `Esc` | 取消模态 / 取消刀片 |

## 钢琴卷帘（需要焦点）

| 键 | 作用 |
| :--- | :--- |
| `D` | 切换 `Select` / `Draw` 模式（`Esc` 也能退出 `Draw`） |
| `G` | 抓取移动 |
| `S` | 缩放 |
| `T` | 拉伸；模态中 `S` 切到首边 |
| `Shift+D` | 复制并抓取 |
| `Ctrl+C` / `Ctrl+V` | 复制选中音符 / 粘贴到播放头（保持音符的相对位置） |
| `K` | 刀片 |
| `X` / `Y` | 模态中锁时间轴 / 锁音高 |
| `Delete` / `Backspace` | 删除选中音符 |
| `↑` / `↓` | 上下一律 |
| `Shift` + `↑` / `↓` | 上下八度 |
| `←` / `→` | 左右一格（跟随当前网格） |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 在多个 clip 之间切换编辑焦点（光标在卷帘上时；其余情况下和 `Tab` 一样切视图） |
| `Ctrl+A` / `Ctrl+Shift+A` | 全选当前 clip 的音符 / 取消选择 |
| `Esc` | 退出模态 / 退出 `Draw` |

## 工具栏

两组按钮，语义不同，不能互换：

| 组 | 表现 | 语义 |
| :--- | :--- | :--- |
| 模式（`Select` / `Draw`） | 互斥；当前模式填充 | 持久：决定「下一次拖拽是什么意思」，直到换模式。点当前模式不会把它关掉 |
| 动作（`Grab` / `Scale` / `Tweak` / `Knife` / `Duplicate`） | 一次性；armed 时描边（不填充） | 只作用于下一次操作：用掉、`Esc` / 右键取消、或被另一个动作顶掉 |

时间轴只有动作组（`Grab` `G` · `Trim` `T` · `Tile` `Shift+T` · `Duplicate` `Shift+D`/`Alt+D` · `Knife` `K`）——那里没有画笔模式，建片段靠双击空轨道。`Duplicate` 按钮与 `Shift+D` 一样复制独立数据；`Alt+D` 才是共享数据的关联复制。

钢琴卷帘是 `[Select][Draw] | Grab G · Scale S · Tweak T · Knife K · Duplicate Shift+D | 网格 ▾ | 长度 ▾ | Randomize · Strum`。从按钮 arming 的抓取点会推迟到指针进入网格的那一帧，所以选区不会在指针移动途中先跳一下；`Duplicate` 按钮只复制（`Shift+D` 会接着进入移动模态）。

## 鼠标

### 时间轴

| 操作 | 结果 |
| :--- | :--- |
| 拖片段主体 | 移动（跟随吸附档位，默认按拍） |
| `Ctrl` + 拖片段 / 拖边缘 | 移动、裁剪、切刀时不吸附（临时关闭吸附与磁吸，落点按最近的 tick） |
| 拖右边缘 | 扩展/缩短片段窗口；靠近音符起止点（8px 内）自动贴边；向右最多扩到最后音符所在小节的末端（写入会自动扩展，无需预留）；没有内容的片段不能延长；平铺片段的周期随之缩放 |
| 拖左边缘 | 调整片段头裁剪：向右裁深、向左恢复（恢复到数据起点为止，再往左拖不动）；靠近音符起止点同样贴边；被裁进内容的边缘显示锯齿带 |
| 双击空轨道 | 插入片段并自动选中（音频轨弹音频文件选择） |
| 双击片段 | 进 `Editor` |
| `Alt` + 双击 / `F2` | 重命名片段 |
| `Ctrl` + 中键单击 | 临时静音 / 取消静音该片段（淡显，内容与位置不变）；触控板没有中键时用 `H` |
| 右键片段 | 打开片段菜单：`Mute`、`Group`/`Ungroup`、`Link Data`/`Unlink Data`、`Properties`、`Delete`（点在选区内保留整选区；点在选区外先单选该片段） |
| 标尺点击 / 拖 | 定位 |
| 标尺 `Ctrl` + 拖 | 画 song loop |
| 标尺右键 | 加 / 删标记 |
| 右键行首轨道名 | 重命名轨道 |
| 拖行首圆点 | 调整轨道顺序 |
| `Ctrl` + 滚轮 / `Ctrl` + `Alt` + 滚轮 | 水平缩放 / 行高；触控板捏合同样缩放时间轴 |
| 中键拖 / 触控板双指滚动 | 平移 |

### Clip 属性面板（时间轴底部）

| 操作 | 结果 |
| :--- | :--- |
| 点 `Clip` 标题行 | 展开 / 收起属性面板 |
| 拖分隔线 | 调高度；拖到最小即收起 |
| 选中 / 点选片段 | 面板显示 active（最后点选的那个）；多选时标题写 `N selected` |
| 改 `Name` | 改片段名（`Enter` / 失焦提交，`Esc` 取消） |
| `Muted` 勾选框 | 片段静音（与 `H` / `Ctrl+中键` 同一开关） |
| 点 `Data` 行的 `▾` | 列出同类数据块（可搜索），选中即换内容，窗口不变 |
| 改 `Data` 名 | 改数据块，所有引用它的片段一起变 |
| 点 `Data` 行的引用数 | `> 1` 时解除共享，当前片段得到私有副本 |
| `Purge N unused` | 清掉引用数为 0 的孤儿条目（保存时的同一套压缩） |

### 钢琴卷帘

| 操作 | 结果 |
| :--- | :--- |
| 拖音符 | 移动 |
| 拖音符边缘 | 裁剪 |
| `Ctrl` + 拖 | 移动/裁剪时不吸附（临时关闭吸附） |
| 双击空白 | 插入音符；片段窗口自动跟随内容——写入会扩到音符结束取整小节，音符缩短 / 删除后窗口同步收缩 |
| `Shift` / `Ctrl` + 点击 | 加选 / 切换选择 |
| 右键 | 删除 |
| `Q` / `L` / `R` / `Shift+G` | 量化 / 连奏 / 去重叠 / 粘合同音高音符（`Notes` 菜单） |
| 标尺点击 / 拖 | 移动播放头（小节吸附；`Ctrl` 关闭吸附） |
| 滚轮 / `Shift` + 滚轮 | 滚动音高 / 沿时间轴滚动 |
| `Ctrl` + 滚轮 / `Ctrl` + `Alt` + 滚轮 | 时间缩放 / 音高缩放；触控板捏合同样缩放时间轴 |
| 中键拖 / 触控板双指滚动 | 平移 |

### 曲线 lane（卷帘下方）

| 操作 | 结果 |
| :--- | :--- |
| 点击空白 | 加锚点（在小节之外也照落：内容与窗口随之增长） |
| 拖锚点 | 移动 |
| 右键 | 删除该处锚点 |
| 点焦点 lane 之外的 lane | 无反应——那些是淡显的 scenery，先点 `editing` 按钮换焦点 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 在 context 里的 clip / 曲线之间轮换焦点 |

### Inspector / 混音台

| 操作 | 结果 |
| :--- | :--- |
| 右键通道条顶部的通道名 | 就地改名（`Enter` 确认 / `Esc` 取消 / 清空回落默认名） |

### Patch

| 操作 | 结果 |
| :--- | :--- |
| 中键拖 | 平移 |
| `Shift` + 滚轮 | 平移（触控板没有中键时用这条；`Shift` 下滚轮走横向轴） |
| 滚轮 | 缩放 |
| 空白右键 / `Shift+A` | 添加节点菜单 |
| 右键端口旁的名字 | 就地改名（`Timeline` 出口改轨道名，`Mixer` 入口改通道名） |
| 拖端口 | 连线 |
| `Ctrl` + 右键拖 | 划断连线 |
| 点连线中点 | 插入效果 / 删除连线 |
| 框选 | 多选 |
| `Delete` / `Backspace` | 删除选中节点或连线 |
| `Ctrl+C` / `Ctrl+V` | 复制选中节点（含选区内部连线）/ 粘贴到光标（保持相对位置） |
| `Shift+D` | 复制选中节点并落到光标处 |
| 双击节点 | 进 `Inspector` |

画布上还有一层焦点逻辑：`G` / `T` / `K` 等命令只在时间轴或卷帘拿到焦点时生效，
工具栏左侧的 `no keyboard focus` 提示消失即表示已就绪。点一下那片区域即可。
